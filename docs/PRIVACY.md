# Privacy notice

Mail Harbor accesses sender, subject, snippet, message ID, and label information
only after the user starts a dry review. Processing happens inside the extension.
Rules, settings, and correction-derived token counts are stored in the browser's
local extension storage. Mail Harbor does not operate an application server and
does not sell, transfer, or use mailbox data for advertising or generalized
model training.

When a user selects suggestions and clicks Apply, Mail Harbor sends only the
necessary message and label modifications to the Gmail API. Disconnect removes
the cached Chrome identity token and requests revocation. Removing the extension
clears its local storage according to browser behavior.

The use of information received from Google APIs will adhere to the Google API
Services User Data Policy, including the Limited Use requirements.

Before public release, host this notice on the same verified domain as the
product homepage and link the identical URL from the OAuth consent screen and
extension UI.
