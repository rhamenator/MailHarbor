Rules and privacy

Mail Harbor processes sender, subject, and snippet locally. It stores rules, correction-derived token counts, and settings in chrome.storage.local. It does not send mailbox content to an application server or train a generalized model.

Connected mode requests the restricted gmail.modify scope because Gmail's API requires it to both inspect message metadata and apply a label to a message. Dry run is the default; every write requires an explicit selection and click.

Use Chrome's extension settings to clear local storage, and Disconnect in the popup to revoke the cached grant.

See the repository documentation before configuring a production OAuth client.
